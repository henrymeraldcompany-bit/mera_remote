Enterprise Core

What is MERA?

MERA (Managed Endpoint Remote Administration) is a unified fleet management system designed for organizational IT teams, field engineers, and system administrators who require authorized control without compromising user trust or security standards.

Consent-First Remote Sessions

Every remote session strictly requires mutual agreement: the administrator initiates the request, and the device owner physically accepts a system prompt showing the administrator's identity and stated purpose.

Transparent Telemetry

Real-time monitoring of legitimate non-invasive metrics: CPU utilization, available RAM, battery health, storage capacity, operating system build, and network connection state without probing private user data.

Instant Device Kill Switch

Computer and mobile device owners remain in permanent control. A single tap or hotkey immediately drops the management session, purges transient tokens, and logs the termination to the central audit log.

Zero-Trust Enrollment

How Pairing Works: Step-by-Step

No devices are ever pre-configured with hardcoded secrets or backdoors. Enrollment requires physical cooperation between device owner and administrator.

01

Agent Launch

The device owner launches the MERA Agent. The agent connects to the control plane and requests a dynamic, cryptographically random 6-digit OTP pairing code.

02

Admin Claims Code

The administrator enters the 6-digit code into the MERA Admin application and assigns a friendly device name (e.g. "Executive Laptop").

03

Owner Confirmation

The device agent receives the claim and prompts the device owner: "Authorize Alice (Admin) to manage this device?" Owner taps Confirm.

04

Mutual Enrollment

Unique device identity tokens (`agt_sec_...`) are issued and encrypted in hardware storage. Live presence status updates to ONLINE.

Enterprise Safeguards

Security by Architecture & Design

MERA strictly rejects malicious and covert surveillance paradigms. Built to pass enterprise infosec reviews and endpoint security scrutiny.

5-Point Verification Guard

Every remote connection rigorously verifies: (1) Authenticated Administrator, (2) Enrolled Device, (3) Valid Device Credentials, (4) Active Real-Time Socket, and (5) Single-Use Cryptographic Session Token.

Zero Stealth Policy

No covert background screen capture, no keylogging, no credential harvesting, and no security software evasion. The device owner can always see when an agent is running and when an administrator is connected.

Connection Recovery Grace

Network interruptions trigger an automatic 30-second recovery grace timer. Reconnections within 30s verify the cryptographic session token to restore sessions seamlessly without exposing tokens.

Deployment Manual

Installation Instructions

Select your target platform below for detailed, step-by-step installation guides.

STEP 1

Download the APK Package

Download mera-android-agent.apk directly to the target Android phone or tablet using the download button above.

STEP 2

Enable "Install Unknown Apps" Permission

When opening the APK, Android will ask for authorization to install from your browser or file manager:

Settings > Security > Install unknown apps > Allow from this source
STEP 3

Launch MERA Agent & Grant Notifications

Launch the installed application. When prompted, grant notification permissions. MERA uses an ongoing notification to ensure the device owner always knows when the service is active.

STEP 4

Pair with Administrator

The screen displays a 6-digit OTP code (e.g. 582-914) valid for 5 minutes. Provide this code to your IT administrator. Once claimed, tap Authorize Device Enrollment on the prompt.

STEP 1

Download the Windows Agent Installer

Download mera-windows-agent.exe onto the target Windows 10 or 11 laptop or desktop.

STEP 2

Windows Defender SmartScreen Notice

Because the agent is an enterprise binary distributed internally, Windows SmartScreen may show an unrecognized app prompt. Click More info and then Run anyway.

STEP 3

Install as Windows Background Service (Optional)

To ensure persistent connection across reboots, open an elevated PowerShell prompt and run:

MERA-Agent-Setup.bat --install-service

The service installs legitimately as MeraRemoteAgent in Windows Services (services.msc).

STEP 4

Pairing & Interactive Kill Switch

The terminal or tray dashboard displays your pairing code. After the administrator claims it, press [C] to confirm. During active sessions, press [K] or tap the red tray button to instantly terminate the session.
