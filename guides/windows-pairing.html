Windows Laptop Enrollment Guide

Learn how to install and enroll a Windows 10 or 11 laptop into the MERA Remote Management ecosystem.

1

Extract the Windows Bundle

Download mera-windows-agent.zip from the Download Center. Right-click and extract the zip archive to your local drive (e.g. C:\Program Files\MERA Agent\).

2

Initiate Enrollment

Launch the interactive enrollment CLI or desktop app: run npm run pair or execute MeraPairing.exe. The agent inspects hardware parameters and contacts the backend.

3

View Pairing OTP

A pairing window opens with a 6-digit OTP code (e.g. 829-104) valid for 300 seconds.

4

Admin Claims from Phone

The administrator enters 829-104 in the MERA Admin mobile app and assigns a friendly name (e.g., "Engineering Laptop - Sarah").

5

Approve on Windows

The Windows dialog updates: "Administrator 'John Doe' wants to manage this computer. Approve?" Click "Approve Enrollment".

6

Background Operation with Tray Controls

The agent is now active in the Windows Notification Area (System Tray). Right-click the MERA icon anytime to check connection health or click "Disconnect Now" to sever remote access.
